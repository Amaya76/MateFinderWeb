Installation guide

⚔️ Install MateFinder on your Discord server

Add the bot directly to your server to organize your Mythic+ keys and receive group alerts in your channels.

🔗 Direct invite link

Add MateFinder to my server

⚙️ How to install it

  1. 1

    Click the invite link above.

  2. 2

    In the Add to server dropdown, choose the Discord server you want to install it on.

  3. 3

    Click Continue, leave the permissions checked, then click Authorize.

🚀 How to use it afterwards

  1. 1

    Open any channel on your server.

  2. 2

    Click the Apps icon on the far right of the message bar (the geometric shapes).

  3. 3

    Select MateFinder to launch the app and build your group.
